## 🚀 Quick Start

### ✅ Prerequisites
- [Node.js](https://nodejs.org) 18 or newer

### 1️⃣ Clone
```bash
git clone https://github.com/sourav-07-s/Customer-Segmentation-model.git
cd Customer-Segmentation-model
```

### 2️⃣ Install and run
```bash
npm install
npm start
```
🎉 Open <http://localhost:3000>
